## 🎯 Project Overview

**Niche Watcher** is a web application that aggregates top posts from multiple sources (HackerNews, Dev.to, CSS-Tricks) and presents them in a curated feed. Users can browse posts and receive weekly email digests.

**Tech Stack**:
- **Backend**: FastAPI 0.104.1 + Uvicorn 0.24.0
- **Database**: PostgreSQL 14+ (Railway)
- **Frontend**: HTML/Jinja2 templates (local)
- **Mobile**: Flutter/Dart (scaffold only, not deployed)
- **Deployment**: Railway.app with dual-service setup

---

## ✅ Completed Features

### 1. **Authentication System** ✅
- Full signup/login/logout with JWT tokens (60-min expiry)
- Password hashing with bcrypt (72-byte UTF-8 limit)
- Aggressive character cleaning (removes invisible chars, control chars)
- Protected routes requiring JWT cookie verification
- User model with email/password in database

### 2. **Database Setup** ✅
- PostgreSQL on Railway with auto-provisioned volume
- 3 tables: `users`, `user_credentials`, `posts`
- Async timeout handling (10s) for initialization
- App continues even if DB unavailable at startup

### 3. **Post Aggregation** ✅
- **HackerNews**: Scrapes 7 last days, retrieves top 10 by score
- **Dev.to**: Uses public API (`/api/articles?top=7days`), retrieves top 10
- **CSS-Tricks**: RSS feed parsing, retrieves top 5
- All sources run in `scheduler.py` via `run_weekly_digest()`

### 4. **Frontend - Posts Page** ✅
- Shows all posts paginated (10 per page)
- **"À la une" section**: Shows top 1 post per source in gradient blue cards
- Featured posts excluded from main feed
- Filter by week number
- Sort by date (latest/oldest)
- Responsive design with dark theme

### 5. **Production Scheduler** ✅
- Railway Cron Job configured (can trigger scheduler every 10 min)
- Created `scheduler_worker.py` (one-time execution)
- `railway.json` configured with dual services: `web` + scheduler function
- Stores posts with week/year ISO dates

### 6. **Deployment** ✅
- Railway.app fully integrated
- `runtime.txt` forces Python 3.11.9
- Dual-service config in `railway.json`
- Web service runs FastAPI on `$PORT`
- Posts automatically populated when scheduler runs

## 🚀 Key Files & Their Roles

### **main.py** - FastAPI Application
- Route: `@app.get("/")` → Home page (requires auth)
- Route: `@app.get("/posts")` → Posts page with pagination + featured section
- Route: `@app.get("/login")` → Login page
- Route: `@app.get("/logout")` → Logout (clears JWT cookie)
- Lifespan event: DB initialization with 10s timeout
- Featured posts: Top 1 per source (sorted by likes, then date)
- Excluded featured posts from main paginated feed

### **scheduler.py** - Post Aggregation
```python
run_weekly_digest():
    - Calls RSSService().fetch_posts()
    - Gets: HN (10) + Dev.to (10) + CSS-Tricks (5) = ~25 posts
    - Saves each to DB with week/year ISO dates
    - Sends emails to subscribed users
```

### **rss_service.py** - All Content Sources
1. `_fetch_hackernews_posts()` - Scrapes 7 days, top 10
2. `_scrape_devto()` - Calls dev.to API, retrieves 10
3. `_fetch_other_feeds()` - RSS parsing for CSS-Tricks, etc.

### **posts.html** - Featured Section
```html
{% if featured_posts %}
  <div class="featured-section">
    <h2 class="featured-title">⭐ À la Une</h2>
    <div class="featured-grid">
      {% for source, post in featured_posts.items() %}
        <div class="featured-card">  <!-- Gradient blue card -->
          ...
```

## 🛠️ Setup & Local Testing

### Prerequisites
```powershell
# Install Python 3.11+
python --version  # Should be 3.11.x

# PostgreSQL locally (via docker-compose or direct install)
docker-compose up -d  # Starts postgres + pgAdmin on localhost:5432
```

### Local Environment
```bash
cd backend
pip install -r requirements.txt
cp .env.example .env  # Configure with local DB URL
```

### Running Locally
```bash
# Terminal 1: Start FastAPI
cd backend
uvicorn main:app --reload

# Terminal 2: Run scheduler once
python scheduler.py

# Terminal 3: Test scheduler in loop
python scheduler.py --loop  # Every 10 minutes
```

### Clear Posts (Local DB)
```bash
psql -U niche_watcher -d niche_watcher -h localhost
TRUNCATE TABLE posts RESTART IDENTITY;
\q
```

### Current Setup

2. **Service 2 - Scheduler Function**: Triggered by Cron job

### To Deploy Changes
```bash
git add .
git commit -m "Your message"
git push origin dev_postgre
# Railway auto-deploys on push
```

### Configure Cron in Railway Dashboard
1. Go to Project → Railway Dashboard
2. Select scheduler service → Settings → Cron
3. Schedule: `*/10 * * * *` (every 10 minutes)
4. Command: Will use `railway.json` startCommand
